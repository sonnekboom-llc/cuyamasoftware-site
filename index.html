How we work

The same rules apply across our products.

  • Private by default

    Records and documents are visible only to the people given access. Each customer's data is kept separate from every other customer's.

  • History is kept

    Changes and corrections are added to the record instead of replacing it, so earlier versions stay available.

  • Exact amounts

    Money is stored as exact whole-cent values and is never rounded along the way.
